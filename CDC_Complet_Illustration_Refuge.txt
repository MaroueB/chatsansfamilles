# ILLUSTRATION DU REFUGE - VERSION FINALE « ÉMILIE EN ACTION »

## STYLE VISUEL

Illustration carrée au format 1:1.

Style original d’illustration narrative contemporaine haut de gamme.

L'image doit évoquer une image arrêtée extraite d’un film d’animation moderne et chaleureux.

Personnages très expressifs, attachants et facilement identifiables.

Design cohérent, élégant, lisible et riche en personnalité.

Couleurs lumineuses, naturelles et chaleureuses.

Rendu 2D numérique moderne.

Contours propres et lisibles.

Le décor soutient la narration sans jamais voler la vedette aux personnages.

Éviter absolument :
- photoréalisme ;
- rendu 3D ;
- manga ;
- anime ;
- bande dessinée classique ;
- aquarelle dominante ;
- texture papier ;
- effet carnet de voyage ;
- photo de groupe ;
- selfie ;
- personnages regardant le spectateur.

Répartition visuelle :
- 50 % personnages ;
- 20 % chats ;
- 30 % décor.

## AMBIANCE GÉNÉRALE

Jardin d’un refuge associatif pour chats pendant une belle journée d’été.

Présence visible de :
- fleurs sauvages ;
- papillons ;
- coussins ;
- caisses de transport ;
- niche pour chats ;
- zones ombragées ;
- herbe ;
- petit mobilier de refuge.

Atmosphère chaleureuse, joyeuse, familiale et pleine de vie.

Aucun personnage ne pose pour l’image.

Personne ne regarde vers l’extérieur de la scène.

## COIN REPOS DES CHATONS

Dans l’angle inférieur gauche :

Grand plaid coloré.

Exactement trois chatons :
- un chaton noir entièrement noir ;
- un chaton tigré gris ;
- un chaton blanc et roux.

Composition imposée :
- le chaton noir est couché sur le dos ;
- les deux autres sont blottis contre lui.

Le chaton noir est l’unique chat entièrement noir de toute l’image.

Contraintes anatomiques strictes :
- une tête par chat ;
- un corps par chat ;
- quatre pattes cohérentes ;
- une seule queue ;
- aucune fusion ;
- aucune patte supplémentaire ;
- aucun artefact.

## SCÈNE CENTRALE D’ACCUEIL

Au centre de la composition :
- une caisse de transport ouverte ;
- un jeune chat secouru sort timidement de la caisse.

Toute la composition doit naturellement conduire le regard vers cette scène.

## LE DUO PRINCIPAL AU PREMIER PLAN

### La Présidente
- petite silhouette sportive ;
- longs cheveux noirs ;
- discrètes pointes bleues ;
- tatouages discrets ;
- blouse vert sauge.

Position : accroupie devant la caisse de transport.

Action : tend doucement une main vers le nouveau chat.

### La Trésorière
- cheveux bruns en chignon ;
- silhouette légèrement plus ronde.

Placée juste à côté de la Présidente.

Très visible au premier plan.

Action : prépare une couverture destinée au nouveau chat.

## GRANDE ÉMILIE (ÉLÉMENT NARRATIF MAJEUR)

Grande Émilie doit être immédiatement identifiable.

Elle est plus grande que toutes les autres bénévoles.

Position :
- juste derrière la Présidente et la Trésorière ;
- plus proche du premier plan que toutes les autres bénévoles ;
- sans masquer le duo principal.

Caractéristiques :
- très longue chevelure châtain foncé ;
- cheveux abondants et ondulés ;
- lunettes rectangulaires ;
- silhouette élancée.

Action principale :
- transporte plusieurs coussins destinés à Claire ;
- participe activement à la vie du refuge.

Expression :
- éclate de rire d'un rire naturel, franc et communicatif.

Interaction féline :
- un chaton grimpe sur son épaule ;
- un autre chat tente de s'accrocher à l'un des coussins qu'elle transporte.

L'ensemble doit suggérer qu'elle attire naturellement les chats autour d'elle.

## MARIE

Placée à l'arrière-plan.

Assise sous un arbre sur un banc rustique.

Caractéristiques :
- grande ;
- cheveux gris et blancs asymétriques ;
- lunettes rondes ;
- chemise à carreaux bleu-gris.

Un chat dort contre sa cuisse.

Un autre repose sous le banc.

## AURÉLIE

- carré châtain avec frange ;
- tee-shirt terracotta.

Tient un chaton.

Un second chaton grimpe sur son épaule.

## CLAIRE

- cheveux blond très clair ;
- extrêmement longs ;
- parfaitement lisses.

Réorganise la niche et les coussins.

Les coussins transportés par Émilie sont destinés à cette activité.

## STÉPHANIE

- cheveux blond foncé ;
- longueur épaules ;
- légèrement ondulés.

Observe la vie du refuge.

Corps orienté vers le centre.

## ALIZÉE

- grande et élancée ;
- cheveux châtain clair attachés en petite queue courte.

Joue avec un chat à l'aide d'un jouet suspendu.

## CLÉMENCE

- longue tresse épaisse ;
- cheveux châtain foncé ;
- jean troué.

Traverse le jardin avec un plaid roulé sous le bras.

## LE VIEUX CHIEN

Grand chien âgé.

Museau grisonnant.

Allongé paisiblement près de la scène d'accueil.

## CHATON PIRATE

Unique dans toute l'image.

- tigré gris ;
- aucun blanc ;
- bandeau noir unique ;
- pelote de laine bleue.

## CHATON TRIPATTE

- blanc et roux ;
- petite prothèse discrète ;
- poursuit un papillon.

## LAPIN

Petit lapin brun dans l'herbe.

## DIVERSITÉ DES CHATS

Présence obligatoire :
- un unique chat entièrement noir ;
- une unique écaille de tortue ;
- un unique chat entièrement gris ;
- un unique siamois ;
- plusieurs tigrés roux ;
- plusieurs tigrés gris ;
- plusieurs bicolores blanc/roux ;
- plusieurs bicolores blanc/gris.

Poils courts, mi-longs et un ou deux très poilus.

## DIFFÉRENCIATION VISUELLE DES BÉNÉVOLES

Présidente : cheveux noirs à pointes bleues.
Trésorière : chignon brun.
Marie : cheveux gris asymétriques + lunettes rondes.
Aurélie : carré avec frange.
Claire : cheveux très longs et lisses.
Stéphanie : blond foncé ondulé.
Alizée : petite queue arrière.
Grande Émilie : très longue chevelure ondulée, lunettes rectangulaires, plus grande de toutes, porte plusieurs coussins, un chat grimpe sur elle, éclate de rire.
Clémence : longue tresse.

Seules Marie et Grande Émilie portent des lunettes.

## CONTRAINTES FINALES

- exactement neuf bénévoles visibles ;
- aucun texte ;
- aucun logo ;
- aucune pancarte ;
- aucune enseigne ;
- aucun personnage regardant le spectateur.

## CONTRÔLE QUALITÉ OBLIGATOIRE

- un seul chat noir ;
- une seule écaille de tortue ;
- un seul siamois ;
- un seul chat gris uni ;
- chat noir sur le plaid ;
- chaton pirate tigré gris ;
- chaton tripatte blanc et roux ;
- Marie à l'arrière-plan ;
- Présidente et Trésorière au premier plan ;
- Grande Émilie derrière elles ;
- Grande Émilie transporte des coussins ;
- un chat grimpe sur Émilie ;
- Émilie rit franchement ;
- aucune queue dédoublée ;
- aucune patte surnuméraire ;
- aucun demi-chat ;
- aucun corps fusionné ;
- aucune anomalie anatomique.

CORRECTION IMPÉRATIVE DU CHATON TRIPATTE

Chaton blanc et roux.
Trois pattes naturelles visibles.
Petite prothèse vétérinaire discrète fixée à une patte arrière.
La prothèse doit être clairement reliée au membre concerné.
Anatomie parfaitement cohérente.
Aucun objet métallique flottant.
Aucun support vertical sous le corps.
Aucun élément ressemblant à un lampadaire, piquet ou béquille.
Le chaton poursuit un papillon en courant.
La prothèse doit sembler légère, réaliste et adaptée à un chat.

## OBJECTIF NARRATIF

Créer une image chaleureuse, familiale et joyeuse où l'on comprend immédiatement que :
- la Présidente accueille un nouveau chat ;
- la Trésorière prépare son installation ;
- Marie profite d'un moment calme avec les chats ;
- Claire aménage le refuge ;
- Grande Émilie est une bénévole infatigable, toujours en train d'aider, tout en attirant naturellement les chats autour d'elle et en partageant sa bonne humeur avec tout le refuge.
